title: Passo reativo
shortCue: Desequilibre-se e recupere-se com um passo para trás
image: ../../../assets/exercises/c6-reactive-step.png
imageAlt: Mulher dá um passo rápido para trás, com os braços um pouco levantados para manter o equilíbrio
category: balance
muscles: [glúteos, quadríceps, estabilizadores do pé]
equipment: [chair]
steps:
  base:
    description: Balance levemente o corpo para trás junto a um apoio e recupere-se com um passo, tocando a mesa
  working:
    description: Desequilibre-se para trás sem apoio e recupere-se com um passo para trás
  advanced:
    description: O mesmo para a frente e para os lados, sem apoio
technique:
  - Apoio por perto, para o caso de uma perda real de equilíbrio
  - Incline-se para trás e deixe o corpo começar a cair
  - Recupere-se com um passo rápido para trás
  - Repita o passo para a frente e para cada lado, 6 vezes cada
mistakes:
  - O passo é dado antes da hora, antes de o corpo realmente se desequilibrar
  - O passo é curto demais para recuperar o equilíbrio
  - Os joelhos ficam rígidos e não amortecem o impacto ao pisar
stopSigns:
  - Queda sem conseguir se segurar no apoio
  - Dor aguda no tornozelo ao pisar
---

Treina exatamente o movimento que evita uma queda quando você tropeça na vida real.
